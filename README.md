# CTS-appen

Privat webapp til indkøb, klargøring og lager af LEGO-sæt for Copenhagen Treasures & Services.

- **App:** statiske filer i roden (`index.html`, `css/`, `js/`), udgivet med GitHub Pages.
- **Maskinrum:** `apps-script/Code.gs` indsættes i Google Apps Script i CTS-kontoen.
- **Guide:** `docs/GUIDE.md` – trin for trin.
- **Test:** `node tests/beregn.test.js` og `node tests/e2e.js` (simuleret forbindelse, `?mock=1`).

Ingen data, regneark, fotos eller nøgler ligger i dette repository. Alt data ligger i Google Sheets og Google Drive.
